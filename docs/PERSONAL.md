# 나만의 뭉치위젯 (personal 브랜치)

배포판(`main`, 태그 `v1.4.6`)과 분리된, 내 PC에서만 쓰는 위젯이에요.

## 브랜치 규칙

| 브랜치 | 용도 | 설치 파일 |
|---|---|---|
| `main` | 지인에게 나눠 주는 배포판. 모두에게 필요한 수정만 | `MungchiWidget-Setup-<버전>.exe` |
| `personal` | 내 위젯. 나만 쓰는 기능·취향 | `MungchiWidget-Personal-Setup-<버전>-me.N.exe` |

- **나만 쓰는 기능** → `personal` 에서 만들고 커밋. `main` 으로는 가져가지 않는다.
- **모두에게 필요한 수정(버그 등)** → `main` 에서 고치고 → `git switch personal && git merge main` 으로 내 위젯에도 반영.
- 버전: personal 은 `<배포판 버전>-me.N` (예: `1.4.6-me.1`). 배포판이 올라가면 `<새 버전>-me.0` 부터.
- 설치는 배포판과 같은 앱으로 덮어쓴다(앱 ID 같음) → 설정·키·할 일은 그대로 유지.
- 설치·확인: `.run/install.cmd` 를 탐색기로 실행 (격리 밖), 끝나면 `install.log` 로 키 3개·금고·자동 실행 확인.

## 설정으로 되는 것 (코드 수정 필요 없음)
이름·사진·성격·말투, 지역, 강조색·테마, 알림 시각, flex·점심시간, 단축키 — 위젯 설정에서 바꾸면 배포판에서도 그대로 유지돼요.
