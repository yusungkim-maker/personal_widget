Windows 바탕화면에 띄워 두는 개인 위젯

할 수 있는 것

  • 시계와 날짜, 지역 날씨(기상청 또는 기본 날씨)와 미세먼지
  • 달력: 구글 캘린더 일정 보기·추가·수정, 공휴일, 날짜가 있는 할 일 표시
  • 할 일과 메모
  • AI 비서 뭉치: 사용자가 이미 쓰는 Claude 또는 ChatGPT 계정으로 동작
  • 알림(일정 몇 분 전, 오늘 마감 할 일, 아침 브리핑)과 빠른 입력 단축키

데이터

  • 설정·할 일·메모·키는 사용자의 PC에만 저장되고, 키는 암호화해서 보관해요.
