개인정보처리방침

뭉치위젯 · 시행일 2026년 10월 1일

1. 요약

뭉치위젯은 사용자의 Windows PC에서만 동작하는 데스크톱 앱이에요. 개발자는 별도 서버를 운영하지 않고, 사용자의 정보를 수집하거나 보관하거나 다른 사람에게 판매·제공하지 않아요.

2. PC에 저장하는 정보

  • 설정(화면 배치, 지역, 알림 시각 등), 할 일, 메모, AI 비서 대화 기록
  • 사용자가 넣은 인증 정보(기상청 인증키, 구글 로그인 토큰): Windows 암호화 기능으로 암호화해서 저장해요
  • 저장 위치: 사용자 PC의 %APPDATA%\Yusk Widget 폴더. 앱을 지워도 이 폴더는 남고, 직접 지울 수 있어요

3. 구글 사용자 데이터

사용자가 구글 계정을 연결하면 아래 권한을 요청해요.

  • 캘린더 일정(calendar.events): 위젯의 달력에 일정을 보여 주고, 사용자가 위젯이나 AI 비서에서 요청한 일정을 추가·수정·삭제하는 데만 써요. AI 비서가 제안한 변경은 사용자가 확인 버튼을 눌러야 반영돼요.
  • 이메일 주소(openid, email): 어떤 계정이 연결됐는지 설정 화면에 보여 주는 데만 써요.

구글 데이터는 사용자의 PC와 구글 서버 사이에서만 오가요. 개발자 서버로 보내지 않고, 광고에 쓰지 않으며, 다른 사람에게 넘기지 않아요. 뭉치위젯의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따라요.

사용자가 AI 비서를 켜 두면, 질문에 답하기 위해 오늘·가까운 날짜의 일정 제목과 시간이 사용자가 고른 AI 서비스(아래 4번)로 함께 전달될 수 있어요. AI 비서를 쓰지 않으면 전달되지 않아요.

4. 사용자가 켠 기능에 따라 직접 연결되는 외부 서비스

아래 서비스는 사용자의 PC에서 바로 연결되고, 각 서비스의 개인정보처리방침이 적용돼요.

  • 날씨: 기상청·한국환경공단(공공데이터포털), Open-Meteo — 고른 지역의 좌표
  • 지역 검색·현재 위치 이름: OpenStreetMap Nominatim — 검색어 또는 좌표. 현재 위치는 Windows 위치 서비스로만 확인해요
  • 달력: 구글 캘린더, 사용자가 넣은 iCal 주소
  • AI 비서: Anthropic(Claude) 또는 OpenAI(ChatGPT) — 사용자의 질문과 위젯 상황 정보(날씨·일정·할 일, 공유를 켠 경우 최근 메모). 비밀번호나 키처럼 보이는 부분은 가려서 보내요
  • flex(근무 시간): 사용자가 로그인한 flex 화면에서 근무 시간 글자만 읽어요

5. 연결 해제와 삭제

  • 위젯 설정에서 구글 연결 해제를 누르면 저장된 토큰을 지우고 구글 쪽 권한도 철회해요. 구글 계정의 서드파티 앱 권한에서도 직접 해제할 수 있어요.
  • PC의 %APPDATA%\Yusk Widget 폴더를 지우면 위젯이 저장한 모든 정보가 지워져요.
