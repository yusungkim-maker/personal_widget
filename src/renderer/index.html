      표시 지역 (최대 3곳)

          구글 캘린더에서 일정 등록하기

          처음 한 번만 필요한 준비 (약 5분)

          구글은 캘린더에 일정을 쓰는 앱마다 "OAuth 클라이언트"를 요구해요. 본인 구글 계정으로 한 번만 만들면 돼요.

          1. Google Cloud 프로젝트 만들기 — 이름은 아무거나 (예: Yusk Widget)
          2. Google Calendar API 에서 사용 누르기
          3. OAuth 동의 화면 설정 — 회사 계정이면 사용자 유형 내부, 개인 계정이면 외부 + 테스트 사용자에 본인 이메일 추가
          4. OAuth 클라이언트 만들기 — 애플리케이션 유형 데스크톱 앱 → 만든 뒤 JSON 다운로드
          5. 아래 JSON 가져오기 → 구글 계정 연결

          구글 캘린더 (읽기 전용 iCal)

          구글 캘린더 → 설정 → 내 캘린더 선택 → 캘린더 통합 → iCal 형식의 비공개 주소를 복사해 붙여 넣으세요.

          AI 비서 성격·지침

          여기 적은 내용은 새 대화를 시작해도 모든 질문에 자동으로 적용돼요. 매번 다시 말할 필요가 없어요.

          AI 비서 (계정 로그인)

          API 키 없이 구독 계정으로 대화해요. 사용량은 각 요금제에서 차감돼요. ChatGPT 는 위젯 전용으로 따로 로그인해서 Codex 앱 계정에 영향을 주지 않아요. 호출할 때마다 구독 로그인인지 확인하고, API 키 로그인이면 실행하지 않아요. 모델은 AI 비서 카드 위쪽에서 고를 수 있어요.
